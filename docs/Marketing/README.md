## How to use these together

The deliverables stack:

1. **Read 01** to internalize the pitch. Everything else assumes you
   know the game in 60 seconds.
2. **Read 05** to lock in what ships in the demo. This is the
   commitment that everything else points at.
3. **Plan against 02** in 30-day chunks. The "concrete next 30 days"
   table at the bottom of that file is the actual starting checklist.
4. **When you're ready to recruit** (Phase 1+ of the marketing plan,
   roughly month 2-3), open **04** to pick platforms and **03** to
   send to candidates. The art priorities in 03 reflect the demo cut
   in 05.
5. **When the age-up screen UI work begins**, follow **06**. That
   screen is one of the highest-leverage features in the entire build.
6. **Update all six** at quarterly intervals. The marketing plan
   especially — platform realities shift fast in 2026.

## Notes / discipline

- These docs reference `shardroot.com` and `info@shardroot.com` as the
  central hub. If those change, find-and-replace across all four files.
- The **art prompts** referenced in 03 live in
  [Assets/Art/Prompts/](../../Assets/Art/Prompts/) — Alanthor + Runai +
  Feraldis already have detailed building descriptions with color codes.
- The **canonical game design truth** is in
  [docs/Design/](../Design/Overview.md). When marketing copy and design
  disagree, design wins, and these docs need to be updated.
- Don't agonize over the studio logo before the Steam page is live (see
  doc 02 — the "what to *not* do" section).
